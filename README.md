# Adidas Sales Analysis 📊

An interactive **Adidas Sales Analysis Dashboard** developed using **Tableau** to analyze sales performance, profitability, products, retailers, regions, and sales methods.

### 📌 Project Features
- Total sales analysis
- Units sold analysis
- Operating profit analysis
- Operating margin analysis
- Sales analysis by retailer
- Product-wise sales analysis
- Regional and state-wise analysis
- City-level sales analysis
- Sales performance over time
- Sales method analysis

### 🛠️ Tools Used
- Tableau
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development

### 📊 Dataset Fields
The analysis uses data containing:
- Retailer
- Invoice Date
- Region
- State
- City
- Product
- Price per Unit
- Units Sold
- Total Sales
- Operating Profit
- Operating Margin
- Sales Method

### 🎯 Objective
The objective of this project is to transform Adidas sales data into an interactive Tableau dashboard that makes it easier to explore sales and profitability across different products, retailers, locations, and sales channels.
